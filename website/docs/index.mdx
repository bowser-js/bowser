# Bowser

<a id="overview"></a>

Bowser is a small, fast browser, platform, and rendering-engine detector for browser and Node.js applications. It parses User-Agent strings and offers an API for checking browser, operating-system, platform, and engine details.

- **Small:** a lightweight parser with an ES5 build for older environments.
- **Selective:** use the parser information you need.
- **Multi-platform:** works in browsers and Node.js.

Bowser 2.0 introduced a substantially changed API. For legacy applications, use the [1.x branch](https://github.com/bowser-js/bowser/tree/v1.x) and install `bowser@1.9.4`.

Start with [installation and usage](./getting-started), explore [Client Hints](./client-hints), or learn how to [filter by browser and version](./filtering).

The [Bowser Online demo](https://bowser-js.github.io/bowser-online/) shows the parser output for a User-Agent string.
