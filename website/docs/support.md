# Support and credits

Bowser is maintained by its contributors. See the [code contributors](https://github.com/bowser-js/bowser/graphs/contributors) and the [financial contributors](https://opencollective.com/bowser).

This project exists thanks to everyone who contributes. [Contribute code](https://github.com/bowser-js/bowser/blob/master/.github/CONTRIBUTING.md).

[![Code contributors](https://opencollective.com/bowser/contributors.svg?width=890&button=false)](https://github.com/bowser-js/bowser/graphs/contributors)

## Financial support

Become a financial contributor to help sustain the project. See the [OpenCollective page](https://opencollective.com/bowser/contribute).
